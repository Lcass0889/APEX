# Lcass0889

Desenvolvimento de apps móveis (iPhone, CarPlay e Android) e de ferramentas com IA que rodam localmente.

## Projetos

- **APEX** — app para quem gosta de dirigir: velocímetro por GPS, alertas de radar pela via e pelo sentido, gravação de rotas, garagem e comunidade com amigos. iPhone (SwiftUI), CarPlay e Android (Jetpack Compose), com backend no Supabase. Em teste fechado.
- **GymFocus** — app de treino em React Native com Expo. [Política de privacidade e termos](https://github.com/Lcass0889/gymfocus-legal).
- **L.E.O.** — assistente de voz que roda localmente: reconhecimento de fala com Whisper, respostas com Ollama e voz com Piper, com clientes desktop e web.
- **Prospector** — encontra negócios locais sem site cruzando dados públicos (CNPJ, DNS, Google Maps e registro.br), com app web e desktop.

Os repositórios desses projetos são privados.

## Tecnologias

Swift e SwiftUI · Kotlin e Jetpack Compose · TypeScript e React · React Native e Expo · Python e FastAPI · PostgreSQL e Supabase · GitHub Actions
